# Latifa Al Jarrah — Portfolio

Next.js (App Router) + TypeScript + Tailwind CSS v4.

## Run
```bash
npm install
cp .env.example .env.local   # fill RESEND_API_KEY
npm run dev
```

## Before deploying
- Add your images to `public/images/`: `latifa.jpeg`, `profolio.png`, `image.png`
- Save the Ultimate Furniture and Chefsupply images to `public/images/` and update `data/projects.ts`
- Set `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL` in Vercel project settings
